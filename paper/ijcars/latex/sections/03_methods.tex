\section{Methods}

\subsection{Data, features and models}

JIGSAWS comprises 103 usable trials from 8 surgeons across suturing, knot-tying and needle-passing, each rated on a modified OSATS instrument whose six 1-5 elements sum to a global rating score (GRS, 6-30). The metadata files, not the directory listing, are authoritative; surgeon G has no usable needle-passing trial, and GRS equals the sum of its elements on all 103 rows.

We compute 16 motion features per trial from the patient-side manipulator channels over the annotated task window, with tool-tip positions low-pass filtered once at 5 Hz before any derived quantity: task time, the correlation between the two instruments' speed profiles, and per instrument the path length, speed mean and standard deviation, mean acceleration, idle fraction below 1 mm/s, hull volume and gripper cycles. Thresholds were fixed before use and never tuned against outcomes; three features were removed before modelling for stated reasons unrelated to performance (S1).

The baseline applies ridge regression to GRS and multinomial logistic regression to the skill label, standardised within a pipeline so scaling uses training rows only; the ridge penalty is chosen inside each training set by leave-one-subject-out search, and the logistic regulariser is fixed at C = 1.0, a subject-level inner search being ill-defined when a class is held by two surgeons. The second path uses a commercial zero-shot decision model (jev-1.13.0), never trained, given the same 16 features rendered as ordinal phrases describing each feature's percentile within its task. No number, identifier or label is transmitted; tests enforce this. Seven five-level scoring questions are sent per trial and each trial was scored three times (S2).

\subsection{Protocols, reference predictor and uncertainty}

The two schemes hold out the \textit{i}-th repetition with every surgeon still in training, or a surgeon entirely. Official skill splits ship only for suturing; our generated folds reproduce them exactly there, verified by test. Every trial is predicted once per scheme.

Claims are stated against a \textbf{feature-free reference} predicting each held-out trial with the mean GRS of its own training fold, so the headline quantity is the reduction in mean absolute error relative to that reference, in GRS points. \textbf{Interpretation rule, fixed before any interval was computed:} a method beats the reference only if the lower bound of its 95\% interval exceeds zero. With eight surgeons this is a weak test and we treat it as suggestive. The zero-shot score is placed on the GRS scale by a line fitted within each training fold, and we record the sign of that slope per fold as a direction guard.

All intervals resample \textbf{whole surgeons} with replacement (2000 resamples), never individual trials, with predictions held fixed; an interval therefore reflects which surgeons were evaluated, not refitting variability. For the central claim we bootstrap the between-protocol difference paired on the same resampled surgeons.

\subsection{Protocol scrutiny and pre-registration}

Analysis rules for each stage were committed to a version-controlled log before the corresponding analysis ran; analyses added afterwards are labelled post hoc below. Two findings about our own protocol belong on record. \textbf{Leakage was tested for and not found:} altering test-fold labels leaves that fold's predictions bit-identical, a deliberately leaky variant moves untouched predictions by 16 GRS points where ours moves them by zero, and 50 shuffled-label refits per cell gave uniformly negative mean correlations, the opposite of leakage. \textbf{Separately, our pre-registered headline statistic proved uninterpretable and was replaced:} under leave-one-user-out each fold is one surgeon and the prediction one constant, so the feature-free reference scores -0.78 to -0.86 on pooled rank correlation by construction. We therefore report error against that reference, retaining correlations only beside it. This substitution is itself post hoc (S3).
